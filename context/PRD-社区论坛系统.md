## 1. 产品概述

### 1.1 产品定位

构建一个面向公众的图文社区论坛，用户可以按版块分区浏览和发布帖子，通过评论、点赞、收藏等方式互动。系统采用前后端分离架构，包含用户前台和管理员后台两套界面。

### 1.2 核心价值

- 为小型社区（<1000 人）提供轻量、易用的交流平台
- 以图文帖子为核心内容形式，降低创作门槛
- 通过版块分区实现内容组织，方便用户按兴趣浏览

### 1.3 目标用户画像

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| 普通用户 | 社区成员，浏览、发帖、互动 | 发现感兴趣的内容，表达观点，建立社交连接 |
| 吧主 | 某板块的负责人（`board.owner_user_id`） | 维护本吧信息、发板块公告、本吧帖子置顶 |
| 管理员 | 社区运营者，管理内容和用户 | 维护社区秩序、全站公告、全站置顶、审核板块申请 |

## 2. 信息架构

### 2.1 版块结构

```
社区首页（三栏：侧栏导航 / 信息流 / 全站公告）
├── 版块 A（如：技术交流）
│   ├── 帖子列表（置顶优先 + 时间倒序）
│   ├── 板块公告列表
│   └── 帖子详情（三栏：导航 / 正文+评论 / 板块公告）
├── 版块 B、C …
├── 弹窗：发帖、编辑帖、个人中心、改密
└── 全站搜索（板块 / 帖子 / 用户）
```

### 2.2 用户体系

```
用户
├── 注册/登录（邮箱）
├── 个人资料（头像、昵称、简介）
├── 个人主页
│   ├── 我的帖子
│   ├── 我的收藏
│   └── 我的关注/粉丝
├── 通知中心
└── 个人中心（弹窗：资料 + 改密）
```

## 5. 一期功能详细说明

### 5.1 用户系统

#### 5.1.1 邮箱注册

**用户故事**: 作为一个新访客，我希望通过邮箱注册账号，以便参与社区互动。

**流程**:
1. 用户填写邮箱、密码、昵称
2. 系统发送验证邮件
3. 用户点击邮件中的验证链接
4. 注册完成，自动登录

**字段规则**:
| 字段 | 规则 |
|------|------|
| 邮箱 | 必填，需验证格式，不可重复注册 |
| 密码 | 必填，最少 6 位，需包含字母和数字 |
| 昵称 | 必填，2-20 个字符，不可重复 |

**边缘场景**:
- 邮箱已注册 → 提示"该邮箱已注册，请直接登录"
- 验证邮件未收到 → 提供"重新发送"按钮，限制 60 秒冷却
- 验证链接过期（24小时） → 提示链接已过期，引导重新注册
- 验证链接被重复点击 → 提示"该链接已使用"
- 密码强度不足 → 实时提示密码要求
- 昵称含特殊字符/敏感词 → 提示"昵称不合规"

#### 5.1.2 登录/登出

**用户故事**: 作为已注册用户，我希望通过邮箱和密码登录，以便使用社区功能。

**流程**:
1. 用户输入邮箱和密码
2. 验证通过后跳转首页
3. 登录状态保持（Token 机制）

**边缘场景**:
- 密码连续错误 5 次 → 账号锁定 15 分钟，提示"登录次数过多，请稍后再试"
- 被封禁用户尝试登录 → 提示"该账号已被封禁"，不透露封禁原因
- 已登录用户访问登录页 → 自动跳转首页
- Token 过期 → 自动跳转登录页，提示"登录已过期，请重新登录"

#### 5.1.3 个人资料

**用户故事**: 作为用户，我希望编辑个人资料，展示我的个人信息。

**可编辑字段**:
| 字段 | 说明 |
|------|------|
| 头像 | 上传图片，裁剪为正方形，限制 2MB |
| 昵称 | 2-20 字符，30 天可修改一次 |
| 简介 | 最多 200 字符 |
| 登录密码 | 个人中心 → 账号安全 → 二级弹窗修改；须校验原密码（6–50 位，含字母数字） |

**交互**：个人资料在 **个人中心弹窗**（`SettingsModal`）中编辑，非独立全页（`/settings` 仅兼容打开弹窗）。

**边缘场景**:
- 头像上传非图片文件 → 提示"请上传图片文件"
- 头像文件过大 → 提示"图片大小不能超过 2MB"
- 昵称修改冷却期内再次修改 → 提示"昵称每 30 天可修改一次，下次可修改时间：YYYY-MM-DD"
- 昵称与他人重复 → 提示"该昵称已被使用"

### 5.2 版块系统

#### 5.2.1 版块管理

**管理员故事**: 作为管理员，我希望创建和管理版块，组织社区内容。

**版块字段**:
| 字段 | 说明 |
|------|------|
| 版块名称 | 必填，不可重复 |
| 版块描述 | 简要说明版块主题 |
| 排序权重 | 数字越大越靠前 |
| 状态 | 启用/禁用 |

**边缘场景**:
- 版块下有帖子时禁用版块 → 帖子仍保留但不在前台展示，提示管理员确认
- 删除有帖子的版块 → 需二次确认，提示"该版块下有 N 篇帖子，删除后帖子将一并隐藏"
- 版块名称重复 → 提示"版块名称已存在"

#### 5.2.2 版块浏览

**用户故事**: 作为用户，我希望按版块浏览帖子，找到感兴趣的内容。

**展示内容**:
- 版块名称和描述
- 帖子数量
- 最新帖子时间

### 5.3 帖子系统

#### 5.3.1 发布帖子

**用户故事**: 作为用户，我希望在指定版块发布图文帖子，分享我的想法。

**帖子字段**:
| 字段 | 规则 |
|------|------|
| 所属版块 | 必填，从启用的版块中选择 |
| 标题 | 必填；弹窗发帖为 5–31 字（与贴吧风 Modal 一致），接口校验 2–100 字 |
| 正文内容 | 必填；弹窗为纯文本，提交时转 HTML 段落 |
| 图片 | 可选，最多 9 张，单张限制 5MB |

**发帖/编辑入口**：顶栏「发帖」、板块页发帖 → `PostEditorModal`；作者编辑 → 同 Modal（`openForEdit`）。

**边缘场景**:
- 标题为空 → 提示"请输入帖子标题"
- 正文为空 → 提示"请输入帖子内容"
- 图片超过 9 张 → 提示"最多上传 9 张图片"
- 图片格式不支持 → 提示"仅支持 JPG、PNG、GIF 格式"
- 图片过大 → 提示"单张图片不能超过 5MB"
- 网络中断时提交 → 提示"网络异常，请稍后重试"，保留已编辑内容
- 选择已禁用的版块 → 版块列表中不显示禁用版块
- 内容含敏感词 → 提示"内容包含违规信息，请修改后重新发布"（二期实现）

#### 5.3.2 帖子列表

**用户故事**: 作为用户，我希望浏览帖子列表，发现感兴趣的内容。

**展示内容**:
- 帖子标题
- 发帖人头像和昵称
- 发帖时间
- 点赞数、评论数
- 帖子摘要（正文前 100 字符）
- 首张图片缩略图（如有）

**排序规则**:
- 默认按发布时间倒序（最新优先）
- 置顶帖子始终显示在最前

**边缘场景**:
- 版块无帖子 → 显示空状态提示"暂无帖子，快来发布第一篇吧"
- 帖子列表为空（搜索无结果） → 提示"未找到相关帖子"
- 分页加载到底 → 显示"没有更多了"

#### 5.3.3 帖子详情

**用户故事**: 作为用户，我希望查看帖子完整内容并参与互动。

**页面内容**:
- **三栏布局**：左统一侧栏 / 中正文+评论 / 右本板块公告列表
- 帖子标题、完整正文、图片网格（单图原比例、多图 1:1 横排最多 3 张）
- 发帖人信息、发帖时间、置顶/已编辑标记
- 作者：编辑（Modal）、删除；吧主/管理员：置顶/取消置顶
- 点赞/收藏、评论区（贴吧风两层展示）

**边缘场景**:
- 帖子已被删除 → 提示"该帖子已删除"
- 帖子作者账号被封禁 → 帖子内容仍可浏览，但作者信息显示"已注销"
- 图片加载失败 → 显示占位图，支持点击重试

#### 5.3.4 编辑/删除帖子

**用户故事**: 作为发帖人，我希望编辑或删除自己发布的帖子。

**规则**:
- 仅帖子作者可编辑/删除自己的帖子（编辑走发帖同款弹窗，非独立编辑页）
- 编辑后显示"已编辑"标记及最后编辑时间
- 删除采用软删除策略；用户删除需二次确认
- 吧主/管理员可在详情页对本吧/全站帖子 **置顶**（见三期 H3）

**边缘场景**:
- 编辑时其他人正在查看 → 查看者看到的是编辑前的版本，刷新后更新
- 删除有评论的帖子 → 帖子及评论标记为软删除，前台不展示，后台可恢复
- 管理员删除他人帖子 → 操作记录到后台日志，支持恢复

### 5.4 互动系统

#### 5.4.1 点赞/取消点赞

**用户故事**: 作为用户，我希望对帖子点赞，表达认可。

**规则**:
- 同一用户对同一帖子只能点赞一次，再次点击取消点赞
- 点赞数实时更新
- 点赞触发通知给帖子作者（二期）

**边缘场景**:
- 快速连续点击 → 防抖处理，只响应一次
- 对已删除帖子点赞 → 按钮置灰，提示"帖子已删除"

#### 5.4.2 评论与回复（树形结构）

**用户故事**: 作为用户，我希望对帖子发表评论，并回复其他人的评论。

**评论规则**:
| 规则 | 说明 |
|------|------|
| 评论内容 | 必填，1-1000 字符 |
| 回复层级 | 最多 2 层嵌套 |
| 回复通知 | 被回复者收到通知（二期） |

**展示（已实现，贴吧风）**:
- 一级评论：大头像 + 昵称 + 正文 + 时间 + 回复
- 二级回复：缩进灰底区域，文案 **「回复 {昵称} : {内容}」**
- 某楼回复超过 2 条：默认展示 2 条，提供 **「展开 N 条回复」**

**后端结构**（不变）:
```
评论 A（depth=1）
├── 回复 A-1（depth=2）
├── 回复 A-2（depth=2）
```

**未实现**：评论点赞、用户等级标签、IP 属地。

**边缘场景**:
- 评论内容为空 → 提示"请输入评论内容"
- 评论内容含敏感词 → 提示"评论包含违规信息"（二期）
- 被评论的帖子已删除 → 提示"帖子已删除，无法评论"
- 被回复的评论已删除 → 提示"该评论已删除"
- 评论区无评论 → 显示"暂无评论，快来抢沙发吧"
- 超过 2 层嵌套 → 回复按钮不可用，提示"回复层级已达上限"

#### 5.4.3 收藏/取消收藏

**用户故事**: 作为用户，我希望收藏感兴趣的帖子，方便后续查看。

**规则**:
- 同一帖子只能收藏一次
- 收藏的帖子可在个人主页查看（二期）
- 收藏帖子被删除时，自动从收藏列表移除

#### 5.4.4 关注/粉丝（二期）

**用户故事**: 作为用户，我希望关注感兴趣的用户，查看其动态。

**规则**:
- 关注/取消关注即时生效
- 关注列表和粉丝列表在个人主页展示
- 关注的用户发新帖时收到通知（二期）

---

### 5.5 搜索功能

**用户故事**: 作为用户，我希望通过关键词搜索帖子。

**搜索范围**: 帖子标题 + 帖子正文

**搜索结果展示**:
- 与帖子列表相同的卡片样式
- 关键词高亮
- 按相关度或时间排序

**边缘场景**:
- 搜索结果为空 → 提示"未找到相关帖子，试试其他关键词"
- 搜索关键词过短（<2字符） → 提示"关键词至少 2 个字符"
- 搜索特殊字符 → 自动转义，不触发系统错误
- 高频搜索 → 限流保护，提示"搜索过于频繁，请稍后再试"

### 5.6 通知系统（二期）

**通知类型**:
| 类型 | 触发条件 | 接收者 |
|------|----------|--------|
| 回复通知 | 有人回复你的帖子或评论 | 被回复者 |
| 点赞通知 | 有人点赞你的帖子 | 帖子作者 |
| 系统公告 | 管理员发布公告 | 全站用户 |
| 关注通知 | 有人关注了你 | 被关注者 |

**通知状态**: 已读/未读，支持全部标为已读

**边缘场景**:
- 通知数量过多 → 分页加载，最新 100 条保留，更早的自动清理
- 通知对应的帖子已删除 → 通知仍显示但标记"相关内容已删除"

## 6. 后台管理系统

### 6.1 管理员登录

**流程**: 独立的后台登录入口，邮箱+密码登录

**安全要求**:
- 后台登录与前台登录隔离，需单独认证
- 登录失败 5 次锁定 30 分钟
- 记录登录 IP 和时间

### 6.2 用户管理

**功能列表**:
- 用户列表（分页、搜索、筛选）
- 查看用户详情（注册信息、发帖数、评论数）
- 封禁/解封用户
- 重置用户密码

**封禁规则**:
| 操作 | 说明 |
|------|------|
| 封禁 | 设置封禁原因（内部记录），用户立即无法登录 |
| 解封 | 解除封禁，用户可正常登录 |
| 封禁影响 | 已发布内容保留但前台不展示，可选择性删除 |

**边缘场景**:
- 封禁正在线的用户 → 下次请求时强制登出
- 封禁管理员自身 → 禁止操作，提示"不能封禁自己的账号"
- 封禁其他管理员 → 需二次确认

### 6.3 内容管理

**帖子管理**:
- 帖子列表（分页、按版块筛选、按时间/状态排序）
- 查看帖子详情、删除/恢复（软删除）
- 置顶/取消置顶（后台 + **前台详情页**，吧主限本吧）
- 加精（规划中，未实现）

**评论管理**:
- 查看帖子下的评论列表
- 删除违规评论（软删除，可恢复）
- 恢复已删除评论

### 6.4 版块管理

**功能**:
- 版块列表
- 创建版块（名称、描述、排序）
- 编辑版块信息
- 启用/禁用版块
- 删除版块（需二次确认，有关联帖子时警告）

### 6.5 公告管理（三期）

**双层公告**：
| 作用域 | 说明 | 管理入口 |
|--------|------|----------|
| site | 全站公告 | 后台「公告管理」；首页右栏展示 |
| board | 板块公告 | 吧主/管理员在板块页；帖子详情右栏展示 |

**字段**：标题 ≤50 字；正文 ≤**1000** 字；支持置顶、排序权重、显示/隐藏。

**权限**：站点公告仅 admin；板块公告为 admin 或该吧吧主。普通用户可 **只读查看** 公告详情。

### 6.6 系统设置（规划中）

原 PRD「站点名称、滚动公告栏」等：全站公告已由 **announcement 表** 承担；其余配置项仍规划中。

## 9. 非功能需求

### 9.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 页面首次加载 | < 3 秒 |
| 接口响应时间 | < 500ms（95th） |
| 图片上传 | 单张 < 5MB，上传 < 10 秒 |
| 并发用户 | 支持 200 人同时在线 |

### 9.2 安全要求

| 要求 | 说明 |
|------|------|
| 密码存储 | 不可逆加密（如 bcrypt） |
| 接口鉴权 | Token 机制，接口级别权限校验 |
| XSS 防护 | 用户输入内容转义输出 |
| CSRF 防护 | 关键操作携带 CSRF Token |
| 文件上传 | 校验文件类型和大小，禁止可执行文件 |
| 敏感信息 | 日志不记录密码、Token 等敏感信息 |

### 9.3 兼容性要求

| 范围 | 要求 |
|------|------|
| 浏览器 | Chrome、Firefox、Safari、Edge（最近 2 个版本） |
| 设备 | PC 端优先，移动端基本可用（响应式） |

## 10. 边缘场景汇总

### 10.1 数据一致性

| 场景 | 处理方式 |
|------|----------|
| 用户被封禁后 | 帖子/评论前台不展示，后台可查看 |
| 帖子被删除后 | 软删除：评论一并标记删除，前台不展示；收藏保留但显示"已删除"；通知标记"已删除"；管理员可恢复 |
| 版块被禁用后 | 已有帖子不展示，但数据保留 |
| 版块被删除后 | 关联帖子一并隐藏，需管理员二次确认 |

### 10.2 并发与冲突

| 场景 | 处理方式 |
|------|----------|
| 同时点赞/取消点赞 | 防抖 + 幂等处理 |
| 同时编辑同一帖子 | 以最后提交的版本为准 |
| 快速连续发帖 | 限流，同一用户 10 秒内只能发一帖 |
| 快速连续评论 | 限流，同一用户 5 秒内只能发一条评论 |

### 10.3 异常状态

| 场景 | 处理方式 |
|------|----------|
| 网络中断 | 提示网络异常，保留已输入内容 |
| Token 过期 | 跳转登录页，提示重新登录 |
| 接口超时 | 提示"请求超时，请重试"，支持手动重试 |
| 404 页面 | 友好的 404 提示页，引导回首页 |
| 500 错误 | 友好的错误提示页，建议稍后重试 |
